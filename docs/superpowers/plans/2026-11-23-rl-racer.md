# RL Racer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A top-down 2D racing game in Python where cars learn to lap a track through from-scratch neuroevolution, REINFORCE, A2C and PPO, with a live viewer, an SB3 answer key and one lesson per stage.

**Architecture:** A headless, batched numpy simulator (track geometry, car physics, sensors, reward) is the core. Learners drive it directly; a thin Gymnasium wrapper serves SB3. Training writes run directories (config, metrics CSV, atomic checkpoints, ghost laps). `pyray` only draws: a `drive` mode for the keyboard and a separate `watch` process that hot-reloads the newest checkpoint.

**Tech Stack:** Python 3.12 via `uv`, `raylib` (provides `pyray`), numpy, PyTorch (CPU wheels), gymnasium, stable-baselines3, matplotlib, pytest. Configs are TOML read with stdlib `tomllib`.

**Spec:** `docs/superpowers/specs/2026-11-23-rl-racer-design.md`

## Global Constraints

- Readability beats speed and brevity. Every module starts with a docstring saying what it does and why; non-obvious lines get a comment explaining the reason, not restating the code.
- Learning algorithms are written from scratch. SB3 appears only in `racer/algos/sb3_ppo.py`.
- Python pinned to `==3.12.*` in `pyproject.toml`; run everything through `uv run`.
- torch comes from the CPU index (`https://download.pytorch.org/whl/cpu`); no CUDA wheels.
- Units are meters, seconds, radians. Physics `dt = 1/60`, independent of rendering.
- Actions for every method: two floats in [-1, 1], `[steer, throttle]` (negative throttle = brake, no reverse).
- Every run is seeded (`--seed`, default 0). Seeded, not bit-identical; multithreaded torch allowed.
- Every number written in a lesson comes from a real run whose `runs/` directory is named in the lesson.
- Out of scope: track editor, drift physics, the Detailed look, GPU training, human-vs-AI, sound.
- Commits: conventional prefixes (`feat:`, `test:`, `docs:`, `chore:`), ending with the session's attribution lines.
- `runs/` and `results/raw/` are gitignored; `results/*.png` and `results/summary.md` are committed.

## Review Focus

1. **A typo in an experiment config key** (e.g. `mutation_sdt`): the run must stop with an error naming the key, never silently use the default. Test: Task 1 `test_unknown_key_raises`.
2. **The viewer reads a checkpoint while the trainer writes it:** the viewer must never load a half-written file, and must show "waiting for first checkpoint" for an empty run. Tests: Task 8 `test_checkpoint_write_is_atomic`, `test_latest_checkpoint_empty_run`.
3. **Progress projection jumping across a hairpin** where two parts of the track lie close: it must not produce a huge false progress reward. Test: Task 3 `test_projection_does_not_jump_hairpin`.
4. **A car wiggling back and forth across the start line:** it must not count laps; only a full lap of forward progress counts. Test: Task 5 `test_start_line_oscillation_counts_no_lap`.
5. **A ray parallel to or collinear with a wall:** it must give a finite distance (max range if no hit), never NaN or inf, because NaN in an observation poisons a whole training run silently. Test: Task 2 `test_parallel_and_collinear_rays_are_finite`.

### Task 3: Track model, spline and projection

**Files:**
- Create: `racer/track.py`, `tracks/oval.json`, `tracks/twisty.json`
- Test: `tests/test_track.py`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - JSON format: `{"name": str, "width": float, "start_index": int, "points": [[x, y], ...]}`. Closed loop implied; point order is driving direction.
  - `@dataclass(frozen=True) Track`: `name: str, width: float, center (M,2), tangent (M,2) unit, normal (M,2) unit (left of tangent), left (M,2), right (M,2), cum_len (M,)` (arc length at each sample, `cum_len[0]=0`), `length: float, start_index: int, spacing: float`. Wall segment `i` of each wall runs from sample `i` to `(i+1) % M`.
  - `catmull_rom_closed(points: (P,2), n_samples: int) -> (n_samples,2)` centripetal (alpha 0.5), evenly re-sampled by arc length.
  - `build_track(name, points, width, start_index=0, spacing=2.0) -> Track` (start_index refers to the control point; converted to the nearest sample).
  - `load_track(path_or_name: str) -> Track` (a bare name like `"twisty"` resolves to `tracks/twisty.json`).
  - `Track.wall_window(idx: (N,), half: int) -> tuple[(N,K,2), (N,K,2)]` segment endpoints of both walls within `idx ± half`, `K = 2*(2*half+1)`.
  - `Track.project(pos: (N,2), hint: (N,) int, half: int = 10) -> tuple[idx (N,) int, s (N,) float]` nearest centerline sample searched only within `hint ± half` (wrapping), and arc length `s` of the projection onto the adjacent segment.
  - `Track.pose_at(s: (N,)) -> tuple[pos (N,2), heading (N,)]` point on centerline at arc length `s` (mod length).
  - `Track.bounds() -> (xmin, ymin, xmax, ymax)` including walls.

### Task 5: Batched simulator

**Files:**
- Create: `racer/sim.py`, `racer/bench.py`
- Modify: `racer/cli.py` (`bench` subcommand)
- Test: `tests/test_sim.py`

**Interfaces:**
- Consumes: `Track` (Task 3), `step_cars`, `car_edges` (Task 4), `ray_distances`, `any_crossing` (Task 2), `EnvConfig` (Task 1).
- Produces:
  - `obs_dim(cfg: EnvConfig) -> int` = `n_rays + 3`. Observation layout: `[rays / ray_range (n_rays), speed / max_speed, steer / max_steer, heading_error / pi]`, heading_error = wrapped angle between car heading and centerline tangent.
  - `@dataclass StepResult`: `obs (N,D), reward (N,), terminated (N,) bool, truncated (N,) bool, lap_completed (N,) bool, lap_time (N,) float (NaN unless a lap finished this step), final_obs (N,D)` (obs before auto-reset; equals `obs` for cars not done).
  - `class BatchSim(track: Track, cfg: EnvConfig, n_cars: int, seed: int = 0, auto_reset: bool = False)`:
    - `reset() -> (N,D)`; `step(actions: (N,2)) -> StepResult` (one decision = `action_repeat` physics substeps; crash checked every substep; rays computed once per decision).
    - `place_car(i: int, s: float, lateral: float = 0.0, heading_offset: float = 0.0, speed: float = 0.0) -> None` (sets state and progress bookkeeping as a fresh spawn at arc length `s`).
    - `set_track(track: Track) -> None` (takes effect on the next reset of each car).
    - read-only for rendering: `state: CarState`, `last_rays: (N,n_rays)`, `alive: (N,) bool`, `laps: (N,) int`, `episode_time: (N,)`.
  - Semantics:
    - Progress: per car, `ds` = wrapped change of projected `s` (`|ds| > length/2` wraps); `traveled += ds`; `max_traveled` tracked.
    - Reward per decision: `progress_scale*ds_sum - time_cost`, `+ lap_bonus` on a lap, `- crash_penalty` on crash.
    - Lap: when `traveled >= (laps+1) * length`; lap time = time since spawn or previous lap.
    - Terminated: crash, or `max_traveled - traveled > wrong_way_m`. Truncated: `episode_time >= max_episode_s` or `laps >= max_laps`.
    - Non-auto-reset mode: done cars freeze (reward 0, `alive` False) until `reset()`. Auto-reset mode: done cars respawn immediately (random arc length if `random_start`, else start).
    - Spawn: `start_index` sample, heading along tangent, speed 0.
  - `bench(n_cars_list=(1, 16, 64, 128, 256), seconds=3.0) -> list[dict]` returning car-steps per second; `racer bench` prints a table.
